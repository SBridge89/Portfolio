AdventureWorks Sales Analytics

An end-to-end SQL and Power BI sales analytics project using the AdventureWorks2022 dataset. The project demonstrates relational data preparation, star-schema modelling, DAX measures and advanced SQL analytical techniques.

SQL Server Power BI DAX Power Query Data Modelling Window Functions

Project Overview

The aim of this project was to build an interactive sales reporting solution that allows users to explore overall sales performance, product performance, customer behaviour and territory performance.

The underlying AdventureWorks relational database was transformed into a reporting data model before being brought into Power BI. The final report combines interactive DAX-based analysis with additional SQL analysis using CTEs and window functions.

Data Modelling

The Power BI model was designed using a star-schema approach, with sales transactions stored at order-line level in a central fact table and descriptive attributes separated into dimension tables.

Star Schema

The core model consists of a central sales fact table connected to dedicated dimensions for customers, products, territories, salespeople and dates.

  • Sales_view – sales transactions at order-line grain
  • Date – calendar and time intelligence
  • Product view – products, categories and subcategories
  • Customer view – customer information
  • Territory view – geographical sales information
  • Sales person view – salesperson information
  • Product performance view An SQL view using CTEs and window functions to analyse product performance.AdventureWorks.html

Relationships use single-direction filtering from the dimensions into the fact table, allowing the same transactional data to be analysed from multiple business perspectives.

Executive Overview

The Executive Overview provides a high-level view of overall sales performance. Key measures such as revenue, orders, quantity sold, average order value and average selling price provide an immediate view of business performance.

Revenue trends and category and territory breakdowns allow users to quickly identify changes in performance before exploring the more detailed report pages.

Product Performance

The Product Performance page explores sales at category, subcategory and individual product level. It identifies the products generating the greatest revenue and allows performance to be analysed over time.

The report also includes SQL-based product analysis using CTEs and window functions to calculate year-on-year performance and all-time product rankings.

Customer & Salesperson

This page analyses the customers and salespeople contributing to sales performance. Users can identify high-value customers, compare customer order behaviour and evaluate salesperson revenue and average order value.

The underlying model keeps customer and salesperson attributes in separate dimensions while the central sales fact table provides the transactional measures used throughout the analysis.

Sales & Territory

The Sales & Territory page examines the geographical distribution of sales and compares the performance of individual territories.

Revenue trends show how territories have changed over time, while the Revenue vs Average Order Value scatter chart provides a different perspective on territory performance by highlighting the relationship between overall revenue and order value.

SQL Analysis

SQL Server was used to prepare the core reporting data and one analytical view demonstrating advanced SQL techniques beyond basic aggregation.

CTEs

Common Table Expressions were used to structure multi-stage analytical queries and make complex transformations easier to read and maintain.

Window Functions

LAG and RANK were used to calculate previous-year performance, year-on-year changes and business rankings without losing the underlying row-level detail.

Performance Analysis

An analytical view was created to evaluate performance, including revenue, order counts, year-on-year growth and product ranking.

Power BI & DAX

Power BI was used as the reporting and visualisation layer, with DAX measures providing reusable calculations that respond dynamically to report filters and slicers.

Measures include total revenue, total orders, average order value, average selling price, year-on-year revenue growth and dynamic rankings.

A dedicated Date dimension enables time-intelligence calculations such as previous-year revenue and year-on-year growth.
